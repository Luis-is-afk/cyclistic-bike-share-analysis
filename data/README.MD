# Data folder

Raw trip files are **not** committed (about 6 million rows; large and subject to the Divvy data license).

To reproduce the analysis, download the monthly files for **September 2025 to August 2026**
(`202509-divvy-tripdata.zip` through `202608-divvy-tripdata.zip`) from the Divvy public data index:
https://divvy-tripdata.s3.amazonaws.com/index.html

Unzip the `.csv` files into this folder, then run `cyclistic_analysis.R` from the repository root.
